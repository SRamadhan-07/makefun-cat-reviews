A Python program — standard library only, no network — that writes one line to /output/entry.txt: a house cat's deadpan one-star review of its human, who opens doors only to close them again and screams at a gifted mouse, ending with the cat declaring itself the landlord. The line is 153 characters, inside the competition's gate of 1 to 200 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
